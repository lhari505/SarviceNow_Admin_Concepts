Personal Developer Instance (PDI)
=================================

Overview
--------

A Personal Developer Instance (PDI) is a free, cloud-based ServiceNow environment provided to developers, administrators, and learners for practicing, testing, and building applications without affecting any production systems.

A PDI contains a complete ServiceNow platform instance where users can safely explore features, create configurations, and develop applications.

* * * * *

After completing this section, you should be able to:

Steps to Obtain a Personal Developer Instance (PDI)
===================================================

Step 1: Navigate to the ServiceNow Developer Portal
---------------------------------------------------

### Navigation

1.  Open a web browser.

2.  Navigate to the ServiceNow Developer Portal.

3.  Click **Sign Up** if you do not already have an account.

* * * * *

Step 2: Create a Developer Account
----------------------------------

### Navigation

1.  Select **Sign Up**.

2.  Enter:

    -   First Name

    -   Last Name

    -   Email Address

    -   Password

3.  Complete account verification.

4.  Sign in to the Developer Portal.

* * * * *

Step 3: Request a Personal Developer Instance
---------------------------------------------

### Navigation

1.  Login to the Developer Portal.

2.  Open the Developer Dashboard.

3.  Locate **Request Instance**.

4.  Click **Request Instance**.

* * * * *

Step 4: Select a Release Version
--------------------------------

### Navigation

1.  Choose the latest available release.

2.  Review release information.

3.  Confirm instance creation.

### Best Practice

Always use the latest stable release version when learning unless instructed otherwise.

* * * * *

Step 5: Save Instance Credentials
---------------------------------

After instance creation, ServiceNow generates:

-   Instance URL

-   Username (admin)

-   Temporary Password

### Example

Instance URL:\
[https://devXXXXX.service-now.com](https://devxxxxx.service-now.com/)

Username:\
admin

Password:\
Generated automatically

### Important

Store these credentials securely.

You will need them every time you log in to your PDI.

==========================

| Term | Definition |
| --- | --- |
| PDI | Personal Developer Instance used for learning and development |

Instance Maintenance
====================

Keeping Your PDI Active
-----------------------

ServiceNow automatically monitors instance activity.

### Inactivity Rule

If an instance remains inactive for approximately 10 consecutive days:

-   Instance may be reclaimed

-   Data may be removed

-   Custom configurations may be lost

### Recommended Practice

Login at least once per week.

### Navigation

1.  Open Instance URL

2.  Login using admin credentials

3.  Verify dashboard access

This activity helps maintain instance availability.
