## 📚 ServiceNow Administrator Learning Journey

### 🚀 Beginner Level

| Lesson | Module | What You'll Learn |
|---------|---------|---------|
| **0** | [Personal Developer Instance Setup](ServiceNow_Admin_Docs/Lesson0_Personal_Developer_Instance.md) | Create your ServiceNow account and obtain a free Personal Developer Instance (PDI). |
| **1** | [ServiceNow Fundamentals](ServiceNow_Admin_Docs/Lession1_ServiceNow_Overview.md) | ServiceNow Overview, Architecture, Environments, Release Cycle & User Interface. |
| **2** | [Records in ServiceNow](ServiceNow_Admin_Docs/Lesson2_Records.md) | Understand what records are, how tables/fields work, and Sys ID concept | Master database fundamentals in ServiceNow |
| **3** | [Lists and Forms in ServiceNow](ServiceNow_Admin_Docs/Lesson3_Working_with_Lists&Forms.md) | Learn how Lists and Forms work in ServiceNow, including navigation, filtering, and record interaction | Master working with ServiceNow UI components like Lists and Forms |
| **4** | [Filters and Search in ServiceNow](ServiceNow_Admin_Docs/Lesson4_Filters_and_Search.md) | Learn how to search, filter, and locate records using Global Search, List Search, Column Search, and wildcards | Master efficient record searching and filtering techniques in ServiceNow |
| **5** | [Condition Builder and Breadcrumbs](ServiceNow_Admin_Docs/Lesson5_Condition_Builder_and_Breadcrumbs.md) | Learn advanced filtering using Condition Builder, Breadcrumbs, saved filters, and reference fields | Create complex queries and efficiently manage ServiceNow data |
| **6** | [Context Menus in ServiceNow](ServiceNow_Admin_Docs/Lesson6_Context_Menus.md) | Learn how to use list, form, column, cell, and field context menus to navigate and manage records efficiently | Improve productivity and administration using ServiceNow context menus |
| **7** | [Modifying Lists and Forms in ServiceNow](Section/Lesson7_Modifying_Lists_and_Forms.md) | Learn how to personalize and configure Lists and Forms, manage layouts, related lists, and form design | Master customization of ServiceNow UI components for users and administrators |
| **8** | [ServiceNow Customizations Overview](ServiceNow_Admin_Docs/Lesson8_ServiceNow_Customizations_Overview.md) | Understand Client-Side vs Server-Side processing and learn the major customization components in ServiceNow | Build a strong foundation for ServiceNow administration and development |
| **9** | [UI Policies in ServiceNow](ServiceNow_Admin_Docs/Lesson9_UI_Policies.md) | Learn how to dynamically control form behavior using UI Policies, including mandatory, read-only, and hidden fields | Master client-side form customization without scripting |
| **10** | [UI Actions in ServiceNow](ServiceNow_Admin_Docs/Lesson10_UI_Actions.md) | Learn how to create buttons, links, and menu items using UI Actions, including client-side and server-side execution | Master interactive form and list customizations in ServiceNow |
